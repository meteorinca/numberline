Number Line (Integers)

Goal: Use a number line to add and subtract negative numbers.

Start at the first number. Then move right for a positive and left for a negative.

Tip: Click a tick on the number line or type the answer. Use “Show move” if you want to see the steps.

More info & examples

Quick rules

  • Start at the first number.
  • Adding a negative = move left.
  • Subtracting a negative = move right.
  • Subtracting a positive = move left.
